お問い合わせ

ご質問・不具合のご報告・ご要望は、次のメールアドレスまでお送りください。順にお返事します。

  • メール：support@tenmeel.com

ご意見は、アンケートでもお送りいただけます。

不具合のご報告では、次のことを送っていただくと、早く調べられます。

  • 何をしたときに起きたか（押したボタンと、その前後の手順）
  • 画面に出たメッセージ（文をコピーして貼り付けるか、画面の写真）
  • 回答のシートの「Tenmeelログ」のタブの、そのときの行（日時・結果・エラーの文が記録されています。生徒の回答は入っていません）
  • 採点の結果についてのご質問では、設問の文・配点・採点方針と、設問の種類（記述式・短文など）
  • お使いのブラウザ（Chrome・Edge・Safari など）

それでも原因が分からないとき

同じことが起きるフォームを、生徒の情報なしで作っていただくのが確実です。

  • フォームの「⋮」→「コピーを作成」で、フォームのコピーを作ります（回答はコピーされません）。
  • コピーに、ダミーの回答（「テスト 太郎」など）を入れて、同じことが起きるか試します。
  • 起きるときは、そのコピーを開発者に共有していただくと、同じ状態で調べられます。共有のしかたは、お返事でお知らせします。

生徒の情報について

  • 生徒の氏名・メールアドレス・回答と、API キーは、メールに書かないでください。画面の写真を送るときも、これらが写らないようにするか、塗りつぶしてください。
  • 本物の生徒の回答が入ったフォームや回答のシートは、開発者に共有しないでください。開発者が先生のフォームや回答のシートを開くことはありません。
  • お送りいただいた内容は、お問い合わせへの回答のためだけに使います（プライバシーポリシーの9）。共有していただいたフォームのコピーは、解決したら開発者の側から削除します。

使い始める

  • 使い始めるまでの流れは、トップページの「使い方」をご覧ください。
  • API キーを用意する前でも、お試しで、採点からコメントが入るまでの流れを確かめられます。
  • Tenmeel は、Google フォームの編集画面の右上にあるパズルのボタン（アドオン）→「Tenmeel」→［開く］で開きます。右側にサイドバーが出ます。

よくある質問

API キーがなくても試せますか？

試せます。お試しでは AI も API キーも使わず、データを外部に送りません。

  • Google フォームで、新しい空のフォーム（「＋ 空白のフォーム」）を作ります。
  • そのフォームで Tenmeel を開き、［このフォームをお試し用にする］を押します。サンプルの設問が入るので、フォームを再読み込みします。
  • フォームの「回答」→「スプレッドシートにリンク」で回答のシートを作り、Tenmeel の［リンクしたので、回答のシートを選ぶ］で、そのシートを選びます。
  • ［採点する（お試し）］を押します。サンプルの回答が送信され、用意した採点結果がフォームと回答のシートに入ります。

［このフォームをお試し用にする］は、設問も回答もない空のフォームでだけ使えます。本物の小テストのフォームが書き換えられることはありません。

API キーはどこで手に入れますか？

Anthropic（Claude の提供会社）の開発者向けの管理画面（console.anthropic.com）で、アカウントを作って API キーを作成します。使うには、Anthropic での支払いの設定が必要です。料金は先生の Anthropic のアカウントに請求され、Tenmeel の開発者には届きません。

API キーは、Tenmeel のサイドバーで一度だけ登録します。キーは先生ごとの Apps Script の保存領域に保存され、ほかの利用者や開発者からは見えません。キーは他人に知られないようにしてください。

費用はどのくらいかかりますか？

現在（パイロット期間中）、Tenmeel は無料です。AI の利用料金は別に、先生が Anthropic に直接お支払いいただきます。目安はトップページの「必要なもの・費用」をご覧ください。

「成績の発表」の設定を聞かれました。

フォームの「設定」→「テストにする」→「成績の発表」を、「確認後に手動で表示する」にしてください。「送信直後に表示する」のままだと、Tenmeel が点数とコメントを書き込んだ時点で、生徒に見えてしまいます。Tenmeel は、採点の前にこの設定を確かめます。

「回答のシートを選ぶ」とは何ですか？

Tenmeel は、採点の結果を、フォームにリンクした回答のスプレッドシートにも書き込みます。フォームの「回答」→「スプレッドシートにリンク」で回答のシートを作ってから、Tenmeel のサイドバーの［回答のシートを選ぶ］で、そのシートを選んでください。フォームごとに最初の1回だけです。Tenmeel が開けるのは、ここで選んだファイルと Tenmeel が作ったファイルだけです。

AI の点数やコメントを直したいときは？

AI の点数とコメントは「案」です。生徒に返す前に、必ず確認してください。直すときは、フォームの「回答」→「個別」で、点数とフィードバックを直します。生徒に返すのは、フォームの「スコアを通知」で先生が行います。Tenmeel が自動で生徒に返すことはありません。

採点方針は、どう書けばよいですか？

採点方針は、サイドバーの「✎ 採点方針を書く」で、テスト全体と設問ごとに書けます。書くときは、次の3つに気をつけると、思ったとおりの点になりやすくなります。

  • AI は、方針に書いた点の刻みで点を付けることが多いです。たとえば「1つにつき5点」とだけ書くと、点は 0・5・10 点のどれかになりやすくなります。
  • 間の点を付けたいときは、その条件も書いてください。例（目的を2つ答える10点の問題）：「目的1つにつき5点。目的は合っているが説明が足りないときは3点。しくみの説明だけでも、目的が読み取れれば2点。」
  • 数え方に迷いそうな答えの扱いも書くと、生徒の間で点がそろいます。例：「1つの文に目的が2つ入っていたら、2つと数える。」

方針を直して［保存］すると、まだ採点していない回答から新しい方針が使われます。採点が済んだ回答に使うには、「↻ 設問を採点し直す」で、設問ごとに採点し直してください（先生が直した答案は、残すか、いっしょに採点し直すかを選べます。採点し直す前の点とコメントは、回答のシートの控えのタブに残ります）。

サイドバーが「読み込み中」のままです。

採点のあとなどは、最新の状態を読み込むのに 20〜30 秒かかることがあります。しばらく待っても出ないときは、サイドバーを閉じて、もう一度開いてください。

生徒の答案は、どこに送られますか？

AI に送るのは、問題文・配点・採点方針と、生徒の回答だけです（記述式（短文）では、満点になっている他の生徒の回答も例として送ります。回答のみで、他の情報は付けません）。送り先は Anthropic の API だけで、生徒の氏名・メールアドレスは送りません（生徒が回答の中に氏名を書いた場合は、そのまま送られます）。採点の処理は先生の Google アカウントの中で行われ、開発者のサーバーは通りません。詳しくはプライバシーポリシーをご覧ください。

AI のモデルを変えられますか？

サイドバーの「⚙ 設定」→「AI のモデル」で、フォームごとに選べます。ふだんは既定のままで使えます。より高性能なモデルにすると、費用は上がります。

画面は英語になりますか？

今のところ、Tenmeel の画面は日本語だけです。

使わなくなったときは？

  • まず、サイドバーの「⚙ 設定」→［APIキーを削除］で、API キーを削除してください。
  • アンインストールしても、API キーは自動では消えません（もう一度入れると、登録したままになっています）。キーを消さずに外してしまったときは、もう一度入れて［APIキーを削除］を押すか、Anthropic の管理画面でキーを無効にしてください。
  • そのあと、Google Workspace Marketplace の Tenmeel のページから、アンインストールしてください。
  • 回答のシートは残ります。Tenmeel が回答のシートに足した列やタブが要らなくなったら、削除してください（フォームの回答そのものには影響しません）。
  • 名簿の機能を使った場合は、マイドライブの「Tenmeel」フォルダと、その中の「Tenmeel名簿」も残ります（このフォルダは、名簿を初めて作ったときに Tenmeel が作ります。名簿を使っていなければ、ありません）。要らなければ削除してください。
  • フォームの説明文に入れた「※AIが作成したコメントを、先生が確認しています」の一文も残ります。要らなければ、フォームの説明文から消してください。

Support in English

Tenmeel is a Google Forms add-on that grades written quiz answers with Anthropic's Claude, using the teacher's own Anthropic API key. The teacher reviews all scores and feedback before returning them to students.

  • Contact: support@tenmeel.com (English or Japanese). Please describe what you did, the message shown, and the related rows of the "Tenmeelログ" (log) tab in the response sheet. Do not include student names, email addresses, answers, or your API key, and do not share forms or sheets that contain real student responses; if needed, we will ask you to share a copy of the form with dummy responses.
  • Language: The add-on's interface is currently in Japanese only.
  • Try it without an API key: In a new, empty form, click the puzzle-piece button (Add-ons) at the top right, then Tenmeel > 開く (Open), and click [このフォームをお試し用にする] (Use this form for a trial). Sample questions are added; reload the form. Link a response spreadsheet (Responses > Link to Sheets), click [リンクしたので、回答のシートを選ぶ] (Select the linked response sheet) and choose it, then click [採点する（お試し）] (Grade - trial). No AI is called and no data leaves your account.
  • Before returning scores: Set Settings > Quizzes > Release grades to "Later, after manual review", so students do not see AI feedback before you check it.
  • Writing grading guidelines: You can write guidelines for the whole quiz and for each question (sidebar: ✎ 採点方針を書く). The AI tends to follow the point steps you write. If you write only "5 points per item", scores tend to be 0, 5 or 10. If you want partial credit, describe it, for example: "5 points per correct purpose. 3 points if the purpose is right but the explanation is thin. 2 points if only the mechanism is explained but the purpose can be inferred." Also say how to count unclear answers (for example, "if one sentence contains two purposes, count it as two") so that scores are consistent across students. After you edit and save the guidelines, they apply to answers that have not been graded yet. To apply them to answers already graded, use ↻ 設問を採点し直す (Regrade a question) in the sidebar and regrade each question (you can choose whether to keep the answers you have corrected yourself or regrade them too; the scores and feedback from before regrading are kept in a backup tab of the response sheet).
  • When you stop using Tenmeel: Delete your API key in the sidebar (⚙ 設定 (Settings) > [APIキーを削除] (Delete API key)), then uninstall the add-on from its Google Workspace Marketplace page. Uninstalling does not delete the key; it is still there if you install Tenmeel again. If you have already uninstalled without deleting it, reinstall and delete it, or disable the key in the Anthropic Console.
  • Feedback: You can also use our survey (in Japanese).
