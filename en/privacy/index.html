Tenmeel Privacy Policy

Effective: November 6, 2026　/　Last updated: November 12, 2026　/　Operator: MC Tech (MCテック, the "Developer")

Tenmeel (the "Add-on") is an add-on for Google Forms that grades teachers' quizzes with written (short-answer and paragraph) questions using AI, and writes scores and comments to the form. This policy explains what data the Add-on handles and how.

This is an English translation of the Japanese privacy policy. If the two versions differ, the Japanese version prevails. The Add-on's screens are in Japanese; Japanese labels are shown in brackets where helpful.

1. The most important points

  • Students' answers never pass through the Developer's servers. Grading runs inside the teacher's own Google account (Google Apps Script). The Developer does not see or receive answers or grading results.
  • Only the questions and students' answers (and the teacher's grading guidelines) are sent to the AI. Student names, email addresses and other information that identifies a person are not included in what is sent to the AI.
  • The AI is used with the teacher's own API key. The teacher pays the AI provider directly for AI usage. The Developer never receives the teacher's API key.

2. Data the Add-on uses, and how

With the teacher's permission (consent on Google's authorization screen), the Add-on uses the following data, only to provide its grading features.

Also used to add or remove a sentence in the form description stating that comments are AI-generated (the teacher's own description text is not changed).
The response spreadsheet linked to the form being graded (the "response sheet")Used to read the responses. Also used to write the AI score, comment, check values and name in columns to the right, and to write a question list, a log, backups made before regrading, and a list sorted by name in separate tabs ("Tenmeel設問", "Tenmeelログ", "Tenmeel控え_…", "Tenmeel名前順"). The teacher creates the response sheet with Google Forms' "Link to Sheets". The Add-on never creates the response sheet itself.
Respondents' email addresses and timestamps (if the form collects them)These are already in the response sheet. The Add-on uses them only to match grading results to the correct response. They are not sent to the AI.
Student names (if the form has a "name" question, or if the teacher registers them in a roster)Used so the teacher can see whose result it is. The Add-on writes the name registered in the roster or, if there is none, the answer to the form's "name" question, to the "Tenmeel｜氏名" (Tenmeel | Name) column of the response sheet (left blank if neither exists). Not sent to the AI. Names are never fetched automatically from school account directories or similar sources.

Not sent to the AI.

3. What is sent to the AI provider

For grading, the following is sent to the AI provider. The only recipient is Anthropic (Claude). The Add-on uses Anthropic's Claude models, and the teacher can switch each form to another Anthropic model.

  • Sent: question text, maximum score (point value), the teacher's grading guidelines (overall and per question), for short-answer questions, examples of other students' answers that received full marks because they matched the form's answer key or because the teacher changed their score to full marks (answers given full marks by Tenmeel in an earlier grading run are not used; answer text only, with no other information), the text of each student's answer, and a matching number (an arbitrary number assigned internally, which does not identify anyone)
  • Not sent: student names, email addresses, response timestamps, response IDs (the ID Google Forms assigns to each response; used only within Tenmeel to write results back to the right response, and recorded in a hidden column of the response sheet), rosters, or any other identifying information

Note: If a student writes their own name or similar information in the answer text, it is sent to the AI as written.

Data sent to Anthropic is handled under Anthropic's Commercial Terms and Privacy Policy. Anthropic's Commercial Terms state that Anthropic does not train its models on content submitted through the API.

The Add-on does not send data to any other AI provider (such as Google Gemini or OpenAI).

The roster spreadsheet is saved in a "Tenmeel" folder that the Add-on creates in the teacher's My Drive (the folder may be moved). The response sheet stays where the teacher created it from Google Forms. All of this is stored in the teacher's Google account, not on the Developer's servers.

5. Retention and deletion

  • The API key can be deleted at any time from the Add-on's sidebar: "⚙ 設定" (Settings) → [APIキーを削除] (Delete API key). Please delete the key this way before uninstalling the Add-on.
  • The response sheet and the roster spreadsheet are in the teacher's Google Drive and remain after the Add-on is uninstalled. If the columns and tabs added by the Add-on are no longer needed, please delete them (this does not affect the form responses themselves). Scores and comments written to the form can be changed or deleted with the form's grading features.
  • The response sheet and the roster contain student names and email addresses (and the response sheet also contains answers). If the teacher shares the response sheet with other teachers, the columns and tabs added by the Add-on (such as AI comments) are also visible to them. Please follow your school's rules for handling personal information when sharing.
  • Grading guidelines and per-form settings are stored in that form's own storage and are deleted together with the form.
  • The Developer does not store or retain any of this data.
  • Access granted to the Add-on can be revoked at any time in your Google Account settings.

6. Sharing with third parties

The Developer does not sell data obtained through the Add-on, use it for advertising, or provide it to third parties. Data is sent to the AI (section 3) only for grading initiated by the teacher.

7. Handling of data obtained from Google APIs

Tenmeel's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. Data obtained from Google Workspace APIs is not used to develop, improve, or train generalized AI and/or machine learning models.

8. Use with minors (high school students and younger)

With the Add-on, AI grades students' answers and writes comments. When grading answers from students under 18, please note the following.

  • The Add-on is operated by the teacher; students never use the Add-on or the AI directly. Students receive scores and comments only after the teacher has reviewed and returned them.
  • Anthropic asks that uses involving minors make clear to users that AI is being used, among other measures (Anthropic's guidelines).
    • Please tell students that the comments they receive are AI-generated. By default, the Add-on shows the sentence "※AIが作成したコメントを、先生が確認しています" (Comments were written by AI and reviewed by the teacher) in the form description. The Add-on adds and removes only this sentence and does not change the teacher's own description. It can be turned off in the settings, but we recommend keeping it on when the Add-on is used with high school students or younger.
    • The Add-on never returns scores or comments to students automatically. Please review them and then return them to students with Google Forms' "Release score". If the form's "Release grades" setting is "Immediately after each submission", comments would become visible to students as soon as they are written, so before the first write to each form the Add-on asks the teacher to confirm that the setting is "Later, after manual review", and does not write if it is not.
  • Please follow your school's and local government's policies (rules for using generative AI, explanations to parents, etc.).

9. Information the Developer receives

The Developer receives only what teachers send in inquiries (by email, etc.), and uses it only to answer those inquiries.

The Add-on has no mechanism that automatically sends usage or error information to the Developer. When reporting a problem, the teacher may be asked to send the contents of the "Tenmeelログ" tab of the response sheet.

Trial mode

The trial mode lets teachers see how the Add-on works without an API key. In a new, empty form, the teacher presses [このフォームをお試し用にする] (Use this form for a trial) to add sample questions. The Add-on then submits sample answers bundled with the Add-on as responses and writes prepared grading results. The trial mode does not call the AI and sends no data to any external party (including the AI provider and the Developer). It works only on forms that carry the sample marker. Because [このフォームをお試し用にする] works only on an empty form with no questions or responses, real quizzes are never overwritten and never receive sample responses. The screen, response sheet and feedback show "サンプルの採点結果です" (These are sample grading results).

10. Security

  • The API key is never written into code or the contents of forms or spreadsheets; it is stored in the teacher's own Apps Script storage (User Properties).
  • Communication between the Add-on and the AI provider is encrypted (HTTPS).

11. Changes to this policy

If this policy changes, we will update this page and show the date of the update. If what data the Add-on uses, or how it uses it, changes, we will announce it in the Add-on's screen before the change and start the new use only after obtaining the teacher's consent.
