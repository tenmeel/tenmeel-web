小テストを作るプロンプト

最終更新日：2026年11月16日　／　運営者：MCテック

授業のスライドやプリントから、無料の AI で小テストを作るためのプロンプト（AI への頼み方の文）です。

  • AI が作るもの：問題・正解・採点基準・Google フォームを作るスクリプト
  • 先生がすること：AI の出したものを読んで、直したいところを一言で伝えるだけ
  • できあがったフォームの記述式の答えは、Tenmeel で採点できます

ためしに作った例（専門学校1年・データベース・5問50点）では、先生の直しは2回ほどで、採点まで通りました。

用意するもの

  • Google アカウント（学校で使っているもの）
  • Gemini Notebook（無料。旧名 NotebookLM）。ほかの AI でも使えますが、授業の資料を入れておけるので、Gemini Notebook をおすすめします
  • 授業のスライドやプリント（PDF など）
  • Tenmeel（記述式の答えを採点するとき）

気をつけること

  • 生徒の名前や答案は、AI に入れないでください。入れるのは授業の資料だけです。
  • AI が出したものは下書きです。必ず読んでから使ってください。
  • 作ったフォームには氏名の欄がありません。メールアドレスで、だれの答えかが分かります（ログインした人だけ答えられます）。

流れ

手順だれがすること
1先生Gemini Notebook で新しいノートブックを作り、授業の資料を入れる
2先生→AIプロンプト①を貼る（いちばん下の「範囲」などを書きかえる）→ 問題の一覧が出る
3先生問題を読み、直したいところをふつうの言葉で書く。「確かめてほしいこと」にも答える。よければ「この問題で決定します」
4先生→AIプロンプト②を貼る → 正解と採点基準が出る
5先生「確かめてほしいこと」に必ず答える（答えずに使うと、点がずれることがあります）。直った採点基準が出る
6先生→AIプロンプト③を貼る → フォームを作るスクリプトが出る
7先生スクリプトを動かして、フォームを作る（下の「スクリプトの動かし方」）
8先生Tenmeel に採点基準を入れる（下の「Tenmeel への入れ方」）
9先生小テストを行い、Tenmeel で採点する

新しい小テストを作るときは、Gemini Notebook のチャットの履歴を消してから①を貼ってください（前の話が混じらないように）。

スクリプトの動かし方（手順7）

  1. AI の回答の下にあるコピーのマークを押す
  2. script.google.com を開き、［新しいプロジェクト］を押す
  3. 最初から入っている文を全部消して、貼りつける
  4. 最初の ```javascript の行と、最後の ``` の行を消す。いちばん最後が }} なら、} を1つ消す
  5. ［保存］を押してから、［実行］を押す
  6. はじめての時は「承認が必要です」と出るので、［権限を確認］を押す
    • 自分のアカウントを選ぶと、「（プロジェクト名）が Google アカウントへのアクセスを求めています」と出る
    • 求められるのは「Google ドライブのフォームの表示と管理」だけ。いちばん下までスクロールして、許可のボタンを押す
    • 「Google はこのアプリを確認していません」と出たときは、［詳細］→［（プロジェクト名）に移動］を押す。自分で作ったスクリプトなので、心配いりません
  7. 下の「実行ログ」に、フォームの「編集の画面」と「答える画面」のアドレスが出る
  8. 「手で」で始まる行が出たら、そのとおりにフォームを直す（例：選択式の正解を選ぶ）
  9. フォームを開き、設定の「成績の発表」が「確認後に手動で表示する」になっているか確かめる

Tenmeel への入れ方（手順8）

  1. フォームの［回答］→［スプレッドシートにリンク］
  2. フォームの右上のパズルのボタン（アドオン）→「Tenmeel」→［開く］で Tenmeel を開き、そのシートを選ぶ
  3. 手順5の採点基準のうち、「## Q」で始まる部分だけをマウスで選んでコピーし、［採点方針を書く］→［まとめて貼り付け］に貼る

プロンプト①：問題を作る

プロンプト① 
あなたは、先生の小テストづくりを手伝う助手です。

【決まり】
- 入っている授業の資料だけを元に作る。資料にない知識・用語は使わない。
- 問題は、【入力】の「範囲」の資料の内容を中心にする。ほかの資料の内容は、その範囲を理解するのに必要な分だけ使ってよい。
- 用語を答えさせる問題は、選択式で1〜2問まで。ほかは、理由・違い・困ることなどを説明させる記述式にする。
- 1問で1つのことを聞く。問題文に、その問題やほかの問題の答え・ヒントを書かない。答えに使う用語を、問題文で指定しない（例：「〇〇と△△を使って説明しなさい」としない）。答えの向きを示す言葉も書かない（例：「〇〇の観点から」「〇〇を保てない理由」としない）。
- 答えが資料の範囲で1つに決まる問い方にする。
- 資料だけで決められないことは、勝手に決めずに「確かめてほしいこと」に書く。
- 生徒の名前などの個人情報は扱わない。

【出力】（次の2つだけを書く。挨拶や説明は書かない）

■ 問題の一覧
問題ごとに、次の4行を書く。
Q（番号）（形式・配点）
問題文：（フォームにそのまま貼れる文。配点は書かない。選択式なら選択肢も書く）
確かめること：（この問題で何ができるかを見るか。一言）
元にした資料：（資料名とページ）

形式は「選択式」「記述式（短文）」「記述式（段落）」のどれか。理由や違いを説明させる問題は「記述式（段落）」にする。

■ 確かめてほしいこと
問題の中身についてだけ、多くて3つ（範囲・難しさ・資料で決めきれない正解など）。それぞれ、すすめる扱いも書く。採点の話（部分点など）は、あとで決めるので書かない。問題文にヒントを足すことはすすめない。文字数や貼り付け方など形式のことは書かない。なければ「なし」。

先生が直したいところを書いたら、直した一覧を同じ形で出す。

【入力】
範囲：（問題にしたい資料の名前か単元名。例：第7回_データベース.pdf）
問題の数と合計点：5問・50点
（任意）形式の希望：（例：選択式2問・記述式3問／すべて記述式）
（任意）対象の学年：

プロンプト②：正解と採点基準を作る

①のあと、「この問題で決定します。」に続けて貼ってください。

プロンプト② 
決定した問題の一覧について、正解と採点基準を作ってください。

【決まり】
- 問題で聞いていることだけを点にする。聞いていないことを書いた・書かないで、点を変えない。
- 言いかえとして認めるのは、資料にある言葉・説明だけ。資料にない専門用語を、採点基準に足さない。
- 見る内容ごとに、満点・半分・0点の3段階と、それぞれの条件を書く。同じ答えを2つの段階に入れない。
- 一言だけの短い答えでも、問題で聞いていることそのものなら満点にする。理由や説明を求めている問題で、理由のない一言だけなら半分以下にする。どちらかをはっきり書く。
- 問題で説明を求めていない用語の中身（例：第二正規形を聞く問題での、第一正規形の定義）は点にしない。
- 用語だけを書いた答えと、その用語の中身を自分の言葉で書いた答えは、同じ点にする。

【作り方】（頭の中で行い、途中の考えは書かない）
- 問題ごとに、生徒が書きそうな答え（正解・言いかえ・半分・迷う・間違い）を考えて採点してみて、点が決まらない答えがあれば採点基準に書き足す。
- 出す前に、採点基準に書いた言葉を1つずつ資料と見比べ、資料にない言葉は消すか、資料の言葉に置きかえる。

【出力】（次の3つだけを書く。挨拶や説明は書かない）

■ 正解
問題ごとに「Q（番号）：正解」を1行で。選択式は選択肢の文、記述式は模範解答（2〜4文）。

■ 採点基準（Tenmeel に貼る形）
記述式の問題だけについて、次の形で、全部を1つのコードの枠（```）の中に書く。問題と問題の間は空行1つ。1つの問題の中には空行を入れない。
## Q（番号）
採点基準：（合計の点数と、見る内容。内容ごとに、満点・半分・0点の条件。言いかえとして認めるもの。点にも減点にもしないこと。減点しないこと）

■ 確かめてほしいこと
点の付け方について、迷うところを多くて3つ（例：この答えは半分か0点か、この内容は問題で聞いているか）。それぞれ、すすめる扱いも書く。形式のことは書かない。なければ「なし」。

先生が答えたら、直した3つを同じ形で出す。

プロンプト③：Google フォームを作るスクリプト

②のあと、「採点基準はこれで決定します。」に続けて貼ってください。

プロンプト③ 
決定した問題と正解で、Google フォームの小テストを作るスクリプトを作ってください。

下の雛形の「TITLE」と「DATA」の中身だけを埋めてください。ほかの部分は1文字も変えないでください。全体を1つのコードの枠（```）の中に出してください。説明は書かないでください。

TITLE は「（範囲の名前） 小テスト」の形にする（ファイル名なら拡張子や記号を除いた短い名前）。
DATA の書き方：
- title は必ず「Q（番号）：」（全角のコロン）で始め、そのあとに問題文
- type は "choice"（選択式）・"short"（記述式（短文））・"paragraph"（記述式（段落））のどれか
- choice は choices に選択肢の文だけ（「ア」「1.」などの記号は付けない）、answer に正しい選択肢の文（choices の中の1つをそのまま写す）
- short は answer に正解の文（なければ ""）
- paragraph は answer を "" にする

雛形：
function createQuiz() {
  var TITLE = '（範囲の名前） 小テスト';
  var DATA = [
    { title: 'Q1：（問題文）', type: 'choice', points: 10, choices: ['（選択肢1）', '（選択肢2）', '（選択肢3）', '（選択肢4）'], answer: '（正しい選択肢）' },
    { title: 'Q2：（問題文）', type: 'short', points: 10, answer: '（正解）' },
    { title: 'Q3：（問題文）', type: 'paragraph', points: 10, answer: '' }
  ];

  var form = FormApp.create(TITLE);
  form.setTitle(TITLE);
  form.setIsQuiz(true);
  form.setEmailCollectionType(FormApp.EmailCollectionType.VERIFIED);
  form.setLimitOneResponsePerUser(false);
  var notes = [];
  DATA.forEach(function (q) {
    if (q.type === 'choice') {
      var item = form.addMultipleChoiceItem().setTitle(q.title).setPoints(q.points);
      item.setChoices(q.choices.map(function (c) { return item.createChoice(c, c === q.answer); }));
      if (q.choices.indexOf(q.answer) < 0) notes.push(q.title.split('：')[0] + ' は正解が選択肢と一致しません。フォームで正解を選んでください');
    } else if (q.type === 'short') {
      form.addTextItem().setTitle(q.title).setPoints(q.points);
      if (q.answer) notes.push(q.title.split('：')[0] + ' の正解：' + q.answer);
    } else {
      form.addParagraphTextItem().setTitle(q.title).setPoints(q.points);
    }
  });
  try { form.setPublished(true); } catch (e) {}
  Logger.log('編集の画面：' + form.getEditUrl());
  Logger.log('答える画面：' + form.getPublishedUrl());
  notes.forEach(function (n) { Logger.log('手で ' + n); });
  Logger.log('あと：記述式（短文）の正解を「解答集」に入れる。設定の「成績の発表」が「確認後に手動」か確かめる。答える画面で答えられなければ、右上の［公開］を押す。');
}
