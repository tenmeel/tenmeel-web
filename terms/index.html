Tenmeel 利用規約

施行日：2026年11月6日　／　最終更新日：2026年11月6日　／　運営者：MCテック（以下「開発者」）

この利用規約（以下「本規約」）は、開発者が提供する Google フォームのアドオン「Tenmeel（テンミール）」（以下「本アドオン」）を利用する条件を定めるものです。本アドオンをインストールまたは利用した方（以下「利用者」）は、本規約に同意したものとみなします。

1. 本アドオンの内容

  • 本アドオンは、利用者が Google フォームで実施した小テストの記述式の回答を、AI（Anthropic の Claude）で採点し、点数とコメントの案をフォームと回答のスプレッドシートに書き込む道具です。
  • 本アドオンは、学校などで生徒の小テストを採点する先生が使うことを想定しています。生徒が本アドオンを直接操作することは想定していません。
  • 本アドオンが扱う情報と、その扱い方は、プライバシーポリシーに定めます。プライバシーポリシーは本規約の一部です。

2. AI の採点結果について

  • AI の点数とコメントは「案」です。AI は誤った点数や、不適切・不正確なコメントを出すことがあります。
  • 生徒に返す前に、利用者が必ず内容を確認してください。成績の評価と、生徒に返す点数・コメントの最終的な判断と責任は、利用者にあります。
  • 本アドオンは、点数とコメントを生徒に自動では返しません。生徒に返す操作（Google フォームの「スコアを通知」など）は、利用者が行います。

3. AI の API キーと費用

  • 採点には、利用者ご自身が Anthropic から取得した API キーが必要です。API キーの取得・管理と、Anthropic への利用料金の支払いは、利用者が行います。
  • 利用者は、Anthropic の利用規約・利用ポリシーに従って API キーを利用してください。Anthropic のサービスの提供・変更・停止・料金について、開発者は責任を負いません。
  • API キーは他人に知られないよう管理してください。本アドオンを使わなくなったときは、サイドバーの「⚙ 設定」→［APIキーを削除］で削除してください。
  • API キーを用意する前でも、お試しモード（AI も API キーも使いません）で動きを確かめられます。

4. 料金

  • 現在（パイロット期間中）、本アドオンは無料で利用できます。
  • 今後、有料のプランを設けることがあります。その場合は、事前にこのサイトと本アドオンの画面でお知らせし、有料の機能は利用者が申し込んだ場合にだけ提供します。

利用者は、次のことを守ってください。

  • 生徒の回答などの情報を、学校・自治体の個人情報の取り扱いのルールと、生成 AI の利用に関するルールに従って扱うこと。必要な場合は、管理職などの確認を得てから利用すること。
  • 高校生以下の生徒の答案に使う場合は、AI が作ったコメントであることを生徒に示すこと（本アドオンは初期設定で、フォームの説明文にその旨を表示します）。
  • Google の利用規約、Anthropic の利用規約・利用ポリシーなど、本アドオンが使うサービスの規約に従うこと。
